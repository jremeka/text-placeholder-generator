# Privacy Policy

Last updated: 3 October 2026

Text Placeholder Generator uses PostHog for anonymous product analytics.

The plugin records when it is opened, which built-in category group is viewed, aggregate fill success or failure counts, and whether an in-session fill is undone. Every event includes `plugin_name: text_placeholder`.

The plugin uses a randomly generated installation ID stored through Figma's plugin storage. This allows events from the same installation to be counted together without using a Figma account name or email address.

PostHog may derive approximate location information, such as country or region, from the network request. This is used for aggregated geographic reporting. The plugin does not intentionally send a precise location.

The plugin does not send Figma file content, file names, document IDs, layer names, existing text, generated placeholder text, Figma account identity, email addresses, or profile information to PostHog.

The plugin remains functional if an analytics request is unavailable or blocked.

## Your choices

The analytics does not contain your name or email, so we cannot locate your events using those details alone. Events are associated with the randomly generated installation ID described above. If you can provide that identifier or enough information for us to locate the relevant analytics, you may request deletion of those events.

Analytics is sent automatically while the plugin is used. The plugin does not currently include an in-product analytics opt-out. You can stop future collection by discontinuing use of the plugin.

## Contact

For questions or privacy requests, use the contact address on the plugin's Figma Community page. Do not post an installation identifier or other private information in a public issue.
